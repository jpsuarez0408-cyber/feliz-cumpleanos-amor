Nuestra Canción Especial 🎵

Gestor de Fotos Públicas

Las fotografías de esta página se cargan directamente desde GitHub Pages. Así, cuando compartas el enlace, cualquier persona podrá verlas desde su celular, computador o tablet.

Cómo agregar fotos

  1. En tu repositorio crea una carpeta llamada fotos.
  2. Dentro crea una carpeta para cada año: 2022, 2023, 2024, 2025 o 2026.
  3. Numera las fotos consecutivamente: 1.jpg, 2.jpg, 3.jpg...
  4. Guarda las imágenes y espera unos segundos a que GitHub Pages publique los cambios.
  5. Recarga la página. Las fotos aparecerán automáticamente en su álbum.
Ejemplo: fotos/2026/1.jpg
fotos/2026/2.jpg
fotos/2026/3.jpg
fotos/2026/4.jpg
Las fotos ya no se almacenan en el navegador: forman parte de tu página pública.
